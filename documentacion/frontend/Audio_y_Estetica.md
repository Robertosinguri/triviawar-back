# 🔊 Audio y Estética Inmersiva

Trivia War no es solo un juego de texto; es una experiencia sensorial diseñada para generar tensión y emoción.

## 🎵 Sistema de Audio Dinámico

El `AudioService` gestiona un banco de sonidos y música que se adapta al estado del juego.

### Música (Ambientes)
- **Dashboard**: Música inspiradora y tranquila que invita a la exploración.
- **Lobby**: Ritmo constante que genera expectativa.
- **Arena**: Música de alta tensión con percusión marcada para aumentar la adrenalina del jugador.
- **Resultados**: Fanfarria para el ganador y música de cierre épica.

### Efectos (SFX)
- **Interacción**: Sonidos de "click" suaves para botones.
- **Feedback de Respuesta**:
  - **Acierto**: Sonido brillante y positivo.
  - **Error**: Sonido sordo y descendente.
- **Alertas**: Sonido de "Tick-Tock" cuando quedan menos de 5 segundos en el reloj.

## 🎨 Identidad Visual

El diseño sigue una línea **Cyber-Modern**:

### Paleta de Colores
- **Fondo**: `#0f0f12` (Negro profundo con matices azulados).
- **Primario**: `#01BA9A` (Verde Esmeralda - Representa aciertos y energía).
- **Secundario**: `#FF4B2B` (Rojo Coral - Representa error y urgencia).
- **Acentos**: Gradientes de cian y púrpura para elementos destacados.

### Tipografía
- **Títulos**: Fuentes sans-serif de peso pesado (como Roboto o Inter) para dar sensación de autoridad.
- **Reloj**: Fuente monoespaciada para asegurar que el contador de tiempo no se desplace visualmente.

---

## ✨ Micro-animaciones
Para que la interfaz se sienta "viva", utilizamos:
- **Hover Effects**: Los botones brillan y se expanden ligeramente.
- **Transiciones de Página**: Fundidos suaves para evitar saltos bruscos entre componentes.
- **Shake Effects**: La arena "tiembla" ligeramente si respondes de forma incorrecta.
