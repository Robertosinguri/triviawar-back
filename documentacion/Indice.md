# 📚 Documentación de Trivia War

Bienvenido a la documentación oficial de **Trivia War**, un ecosistema de juego multijugador en tiempo real impulsado por Inteligencia Artificial.

Este repositorio de documentación está diseñado para ofrecer una visión clara tanto a nivel de usuario como de desarrollador.

## 🗺️ Guía de Navegación

### 🎮 Para Jugadores y Clientes
- [**Manual de Usuario**](Manual_de_Usuario.md): Aprende a jugar, conoce los rangos de dificultad y entiende el sistema de puntuación.

### ⚙️ Para Desarrolladores (Arquitectura)

#### 🖥️ [Backend (Servidor)](backend/Arquitectura_y_Estructura.md)
- [**Core Multijugador (WebSockets)**](backend/Core_Multijugador_Sockets.md): La lógica detrás de las salas y la sincronización en tiempo real.
- [**Motor de IA**](backend/Inteligencia_Artificial.md): Cómo generamos desafíos dinámicos usando Gemini, Groq y otros modelos.
- [**Autenticación y Privacidad**](backend/Autenticacion.md): Gestión de usuarios, Google Login y sistema de Alias.
- [**Referencia de API**](backend/API_Endpoints.md): Listado técnico de endpoints.

#### 🎨 [Frontend (Cliente Angular)](frontend/Tecnologias.md)
- [**Arquitectura Frontend**](frontend/Tecnologias.md): Uso de Angular Standalone, Signals y SCSS.
- [**Servicios de Comunicación**](frontend/Servicios.md): Conectividad con la API y Sockets.
- [**Guía de Componentes**](frontend/Componentes_Clave.md): Desglose de la Arena, el Lobby y el Dashboard.
- [**Estética y Audio**](frontend/Audio_y_Estetica.md): El sistema de sonido inmersivo.
